# Pulse illustration set
Flat duotone tiles, one white line icon, no text, no partner logos. 96×96 viewBox (scales to 320×200 on detail sheets). Six hues rotate (blue, violet, amber, teal, rose, slate); Meet keeps the warm magenta→amber photo grading, Pulse leans cool. Add a service = copy a tile, swap the icon path, pick the next hue. Skylines are 320×90, preserveAspectRatio=none, sit behind a hero with opacity .5–.6.
Usage: `<img src={tile} alt="" className="ux-ticket-photo" />` on tickets and bundle rows; never recolour; never put text inside.
